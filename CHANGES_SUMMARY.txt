================================================================================
  ENVIRONMENT VARIABLES REQUIRED
================================================================================

Required for deployment:

1. MONGO_URI                    - MongoDB connection string
2. GEMINI_API_KEY              - Google Gemini AI API key
3. GOOGLE_CLIENT_ID            - Google OAuth client ID
4. GOOGLE_CLIENT_SECRET        - Google OAuth client secret
5. STRIPE_SECRET_KEY           - Stripe secret key
6. STRIPE_PUBLISHABLE_KEY      - Stripe publishable key
7. STRIPE_WEBHOOK_SECRET       - Stripe webhook secret
8. STRIPE_PRICE_ID_BASIC       - Basic plan price ID
9. STRIPE_PRICE_ID_PRO         - Pro plan price ID
10. STRIPE_PRICE_ID_PRO_PLUS   - Pro Plus plan price ID
11. BASE_URL                    - Your Vercel app URL
12. STRIPE_SUCCESS_URL          - Payment success redirect
13. STRIPE_CANCEL_URL           - Payment cancel redirect

All should be set in Vercel Dashboard → Environment Variables

================================================================================
  NEXT STEPS TO DEPLOY
================================================================================

1. Push to Git Repository
   $ git add .
   $ git commit -m "Reorganized for Vercel deployment"
   $ git push origin main

2. Import Project in Vercel
   - Go to https://vercel.com/new
   - Click "Import Git Repository"
   - Select your repository
   - Vercel will auto-detect vercel.json

3. Configure Environment Variables
   - Go to Project Settings → Environment Variables
   - Add all 13 environment variables listed above
   - Save changes

4. Deploy
   - Click "Deploy"
   - Wait for build to complete
   - Get your URL: https://your-app.vercel.app

5. Test Deployment
   - Visit the URL
   - Test login/register
   - Test phishing detection
   - Verify all features work

================================================================================
  IMPORTANT NOTES
================================================================================

1. Serverless Limitations
   - Max execution time: 30 seconds (60s on Pro plan)
   - Max deployment size: 50MB
   - Cold starts may occur on first request

2. ML Model Considerations
   - Model files included in deployment
   - Loaded on first request (cold start)
   - Consider model optimization if too large

3. Database
   - Use MongoDB Atlas (serverless-compatible)
   - Connection pooling configured
   - Handle connection timeouts

4. Static Files
   - Served directly by Vercel CDN
   - Cached automatically
   - Fast global delivery

5. Alternative Deployments Still Work
   - Heroku: Use Procfile
   - Railway: Use railway.json
   - Render: Use render.yaml
   - Any WSGI server: Use wsgi.py

================================================================================
  TROUBLESHOOTING
================================================================================

Issue: Static files not loading
Solution: Check vercel.json routes configuration

Issue: Import errors
Solution: Verify api/index.py path configuration

Issue: Templates not found
Solution: Check Flask configuration in backend/app.py

Issue: Environment variables not working
Solution: Set in Vercel Dashboard, not just in .env

Issue: Serverless function timeout
Solution: Optimize code or increase maxDuration in vercel.json

Issue: ML model too large
Solution: Compress model or load from external storage
