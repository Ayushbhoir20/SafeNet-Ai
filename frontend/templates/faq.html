Frequently Asked Questions

Find answers to common questions about SafeNet AI

What is SafeNet AI?

SafeNet AI is an advanced AI-powered phishing detection system that analyzes URLs to identify potential phishing threats. It uses a three-layer detection approach combining machine learning classification, WHOIS metadata analysis, and real-time blacklist verification to provide accurate and reliable phishing detection.

The system is designed for educational purposes, academic research, and security assistance, making it suitable for students, researchers, and security professionals.

How does phishing detection work?

SafeNet AI uses a tiered detection approach with three layers:

Layer 1 - ML Detection: A Random Forest machine learning model analyzes URL features, domain characteristics, and behavioral patterns to classify URLs as Safe, Suspicious, or Phishing with a confidence score.

Layer 2 - Blacklist Check: URLs are cross-referenced against known phishing databases (PhishTank) to immediately flag blacklisted sites.

Layer 3 - Content Analysis: For suspicious URLs, the system performs lightweight content analysis to detect phishing indicators like fake login forms, brand impersonation, and suspicious keywords.

Is my data stored? What about privacy?

For Registered Users: If you create an account, your scan history is stored in our database so you can view past scans and statistics in your dashboard. We store URLs you scan, detection results, and timestamps.

Privacy Commitment: We do NOT track your personal identity, browsing history, or any data beyond what's necessary for phishing detection. We do not sell your data to third parties. See our Privacy Policy for complete details.

Security: All passwords are hashed using bcrypt, and data is transmitted over HTTPS encryption.

Can SafeNet AI make mistakes?

Yes. While SafeNet AI achieves high accuracy (95%+), AI predictions are probabilistic and not absolute guarantees. Two types of errors can occur:

False Positives: Legitimate websites incorrectly flagged as phishing. This can happen with new domains, unusual URL patterns, or sites with suspicious-looking features.

False Negatives: Phishing sites not detected. Sophisticated phishing attacks using new techniques may evade detection.

Recommendation: Use SafeNet AI as one component of your security strategy. For critical decisions, verify results independently and exercise caution with suspicious URLs.

Is this suitable for academic projects?

Absolutely! SafeNet AI is designed with academic use in mind and is perfect for:

  • Final Year Projects: Demonstrates real-world application of machine learning in cybersecurity

The system includes comprehensive documentation, clean code structure, and production-ready features that meet academic and industry standards.

What technology stack does SafeNet AI use?

SafeNet AI is built using modern, industry-standard technologies:

  • Backend: Python with Flask framework
  • Machine Learning: Scikit-learn (Random Forest classifier)
  • Database: MongoDB for user data and scan history
  • Frontend: HTML, CSS, JavaScript with responsive design
  • Security: Bcrypt password hashing, HTTPS encryption
  • APIs: WHOIS lookup, PhishTank blacklist integration
How accurate is the detection?

SafeNet AI's machine learning model achieves approximately 95% accuracy on test datasets. The tiered detection approach further improves reliability by combining multiple detection methods.

Performance Metrics:

  • Accuracy: ~95%
  • Precision: High (few false positives)
  • Recall: High (catches most phishing sites)
  • Real-time processing: Results in seconds

Accuracy may vary based on the sophistication of phishing attacks and the novelty of techniques used.
